# CLAUDE.md — Subsoil

Ты работаешь над **Subsoil** — холдинговой платформой на домене `nanocem.app`. Полная документация — в `docs/subsoil/`. Перед любой задачей прочитай `docs/subsoil/README.md` и файл, относящийся к задаче.

## Что строим

- Публичная витрина (`/`) — описание платформы в стиле corva.ai, без живых данных клиентов.
- Кабинет (`/app`) — за логином. Главный экран — **Сводка холдинга**: показатели + требования.
- Модули кабинета: Промысел (бывший OilField Interact), NanoCem UT-9, Недропользование, Отчёты, AI-помощник.

## Стек

- `apps/web` — Next.js 15 (App Router), TypeScript, Tailwind, TanStack Query, ECharts.
- `apps/api` — NestJS (код OilField Interact, расширяется модулями `holding`, `subsoil`, `nanocem`).
- `packages/shared` — типы, zod-схемы, формулы показателей.
- `packages/ui` — дизайн-токены стиля nanocem.app (см. `09-design-system.md`).
- PostgreSQL + Redis на Railway.

## Правила

1. Язык интерфейса — русский по умолчанию, ключи i18n для казахского и английского.
2. Никаких данных скважин и клиентов на публичных страницах. Всё живое — только под `/app`.
3. Каждый запрос к данным фильтруется по `company_id` и `field_id` пользователя (см. `07-roles-access.md`). RLS в PostgreSQL — вторая линия защиты.
4. Формулы показателей живут только в `packages/shared/metrics.ts` и покрыты тестами. Веб и API импортируют их оттуда.
5. Цвет в интерфейсе — только для статусов (норма / внимание / критично). Остальное монохром.
6. Даты — `Asia/Aqtobe`. Числа — с пробелом-разделителем тысяч и запятой в дробях (`1 234,5`).
7. Старые URL nanocem.app не ломать — 301-редиректы по таблице в `00-migration.md`.
8. Миграции БД — только через миграции, никаких ручных правок в проде.
