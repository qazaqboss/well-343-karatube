# 09. Дизайн-система (стиль nanocem.app)

Subsoil наследует текущий стиль nanocem.app, чтобы витрина, кабинет и мобильное приложение выглядели одним продуктом.

## 1. Принципы

- Строгий монохром: белый фон, светло-серые панели, чёрный текст.
- Цвет — **только** для статусов.
- Карточки с общими тонкими рамками, без скруглений и теней.
- Крупные заголовки капсом, мелкие подписи капсом с разрядкой.

## 2. Токены

```ts
// packages/ui/tokens.ts
export const color = {
  bg:        '#FFFFFF',
  panel:     '#F4F4F2',
  ink:       '#111111',
  inkQuiet:  '#6B6B6B',
  line:      '#E2E2DE',
  ok:        '#2E7D32',   // норма / положительный эффект
  warn:      '#B7791F',   // внимание
  crit:      '#C62828',   // критично / простой / просрочено
  none:      '#9E9E9E',   // нет данных
};

export const font = {
  display: '"Oswald", sans-serif',   // заголовки, капс
  body:    '"Inter", sans-serif',    // текст и цифры
};

export const size = { xs: 11, sm: 13, md: 15, lg: 20, xl: 32, hero: 64 };
export const space = 8;              // шаг сетки
export const radius = { none: 0, btn: 2 };
```

Тёмная тема: `bg #111111`, `panel #1A1A1A`, `ink #F2F2F2`, `line #2A2A2A`; статусные цвета те же.

Цифры — `font-variant-numeric: tabular-nums`, чтобы колонки в таблицах не прыгали.

## 3. Компоненты

| Компонент | Описание |
|---|---|
| `KpiCard` | Подпись капсом 11px, значение Inter 32px, дельта со стрелкой ▲▼ (цвет по смыслу, а не по знаку: рост воды — warn) |
| `AttentionList` | Строки с цветной точкой статуса, текстом и ссылкой `→` |
| `AssetTable` | Таблица с точкой статуса в первой колонке, сортировка, разворот до скважин |
| `StatusDot` | 8px круг: ok / warn / crit / none |
| `ScopeSwitcher` | Хлебные крошки Холдинг ▸ Компания ▸ Месторождение с выпадающими списками |
| `ModuleCard` | Номер `01`, заголовок Oswald, строка, `Открыть →` (как на текущей главной) |
| `Hero` | Серый блок, крупный бледный текст на фоне (дата или код объекта, как «J1-IV») |
| `Button` | Чёрная, капс, радиус 2px; вторичная — контурная |

## 4. Графики (ECharts)

- Линия факта — `ink`, план — пунктир `inkQuiet`, сетка — `line`.
- Отметки заходов UT-9 — вертикальные метки с подписью.
- Без заливок под линией и без градиентов.
