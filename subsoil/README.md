# Subsoil — холдинговая платформа

**Subsoil** — базовый сайт холдинга. Он заменяет nanocem.app как точку входа: на домене nanocem.app теперь живёт Subsoil, а NanoCem UT-9, OilField Interact и контур недропользования становятся его модулями.

Главная задача — дать руководству один экран, на котором видно:
- **текущие показатели** — добыча, обводнённость, фонд, эффект от заходов UT-9;
- **требования** — обязательства по контрактам, сроки отчётности, лицензии, что просрочено и что горит.

## Что куда переезжает

| Было | Станет |
|---|---|
| `nanocem.app` (статический сайт NanoCem) | `nanocem.app` → **Subsoil**: публичная витрина + кабинет руководства |
| `ofiapi-production.up.railway.app` (OilField Interact) | модуль **Промысел** внутри Subsoil, сервис `api` в Railway-проекте Subsoil |
| `nanocem.app/erp/`, `/stages.html`, `/ai` | модуль **Недропользование** (требования, сроки, отчёты, AI) |
| `nanocem.app/product.html`, `/plan.html`, `/sealing.html`, `/water-cut.html` | модуль **NanoCem UT-9** |

## Как пользоваться

1. Положить папку `docs/subsoil/` в корень репозитория основного сайта.
2. `CLAUDE.md` — в корень репозитория (его читает Claude Code).
3. Идти по `11-roadmap.md` сверху вниз; каждый этап ссылается на нужные файлы.
