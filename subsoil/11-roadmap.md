# 11. Дорожная карта

Шесть этапов. Каждый заканчивается работающим результатом, который можно показать руководству.

## Этап 1. Монорепозиторий и перенос OFI
- Создать монорепо `subsoil/` (`apps/web`, `apps/api`, `apps/worker`, `packages/shared`, `packages/ui`).
- Перенести код OilField Interact в `apps/api`, бренд → Subsoil, «IC Petroleum» → из настроек компании.
- Railway-проект `subsoil`, БД перенесена (`10-railway-deploy.md`).

**Готово, когда:** OFI работает из нового проекта на `api.nanocem.app`, старые пользователи входят.

## Этап 2. Иерархия холдинга и данные со старого сайта
- Таблицы `holdings`, `companies`, `contracts`, `obligations`, `reporting_*`, `nanocem_jobs`, `production_plans` (`05-data-model.md`).
- Сиды: всё со старого nanocem.app (фонд, заходы, контракты, сроки).
- Роли и доступ (`07-roles-access.md`).

**Готово, когда:** в БД есть все компании и месторождения, у каждого пользователя корректный доступ.

## Этап 3. Сводка холдинга (MVP для руководства)
- API `/holding/*` (`06-api.md`).
- Экран `/app` по макету `03-holding-dashboard.md`: внимание сегодня, 5 KPI, таблица активов, график, требования на 30 дней.
- Переход Холдинг ▸ Компания ▸ Месторождение.

**Готово, когда:** руководитель открывает `/app` и видит реальные цифры и сроки; каждое число ведёт к источнику.

## Этап 4. Витрина и переключение домена
- Публичные страницы (`08-public-site.md`) в стиле `09-design-system.md`.
- Редиректы старых URL (`00-migration.md`).
- Переключение `nanocem.app` на сервис `web`.

**Готово, когда:** nanocem.app открывает Subsoil, все старые ссылки ведут на новые страницы, живые данные доступны только по логину.

## Этап 5. Модули целиком
- NanoCem UT-9: обзор, программа, герметичность, заход.
- Недропользование: контракты, обязательства, карта отчётности, календарь, этапы.
- Отчёты: суточная сводка, отчёт по этапу, паспорт скважины.

**Готово, когда:** старый функционал nanocem.app полностью доступен внутри `/app`.

## Этап 6. Автоматизация и AI
- Снимки 06:00 и рассылка 07:00 в Telegram.
- AI-помощник: RAG по нормативке + инструменты к API.
- Скоринг кандидатов UT-9.
- Мобильное приложение OFI (PWA → Expo) в новом бренде.

**Готово, когда:** руководство получает утреннюю сводку без входа на сайт, AI отвечает и по нормам, и по данным.
