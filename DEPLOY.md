# Перенос nanocem.app на Railway — сценарий для Claude в Chrome

Работа идёт в одной группе вкладок. Сначала откройте их все, потом скопируйте промпт целиком
в Claude в браузере. Логины не нужны — агент работает в ваших уже открытых сессиях.

## Вкладки в группе (открыть заранее, по порядку)

| № | Вкладка | Зачем |
|---|---|---|
| 1 | https://railway.com/dashboard | сервисы, переменные, том, деплой |
| 2 | https://subsoil-ai-production.up.railway.app/ | проверка, что новый сайт поднялся |
| 3 | https://vercel.com/qazaqboss-projects/well-343-karatube/settings/domains | отвязать домен от проекта |
| 4 | https://vercel.com/qazaqboss-projects/~/domains | DNS-записи домена |
| 5 | https://nanocem.app/ | финальная проверка |
| 6 | https://github.com/qazaqboss/well-343-karatube | справка по репозиторию |

## ПРОМПТ (копировать целиком)

```
Ты работаешь в моей группе вкладок в Chrome. Задача — перевести сайт nanocem.app с Vercel на
Railway так, чтобы один сервис Railway отдавал всё: сайт аналитики скважин, AI-помощника и ERP.
Домен остаётся зарегистрированным в Vercel, меняются только DNS-записи.

Правила работы:
— Иди строго по шагам, не забегай вперёд.
— Там, где написано «СТОП», остановись, напиши мне результат и жди ответа.
— Ничего не удаляй, кроме того, что прямо указано в шагах.
— Если название кнопки в интерфейсе отличается от указанного, найди ближайшую по смыслу.
  Если не уверен — не жми, спроси меня.

═══ ЧАСТЬ 1. Railway: один сервис из нужного репозитория ═══

1. Вкладка 1 (railway.com/dashboard). Найди проект, в котором есть сервис с публичным доменом
   subsoil-ai-production.up.railway.app. Открой этот сервис. Это рабочий сервис — в нём уже
   настроен ключ Anthropic.

2. Settings → раздел Source. Смени подключённый репозиторий на qazaqboss/well-343-karatube,
   ветка main. Настройки сборки не трогай: в репозитории лежит Dockerfile, Railway возьмёт его сам.

3. Вкладка Variables. Проверь переменные:
   — ANTHROPIC_API_KEY должна уже существовать. Если её нет — СТОП, скажи мне.
   — DB_PATH со значением /data/erp.db — добавь, если её нет.

4. Settings → Volumes. Если тома нет, создай том с точкой монтирования /data.
   Это нужно, чтобы данные ERP не стирались при каждом деплое.

5. Запусти деплой (Deploy или Redeploy) и дождись статуса Success.
   Если сборка упала — СТОП, пришли мне последние 30 строк лога.

6. Перейди на вкладку 2 и проверь пять адресов. Открывай по очереди и опиши, что видишь:
   — https://subsoil-ai-production.up.railway.app/ → главная «Аналитика фонда и недропользование»
   — .../stages.html → страница «Семь этапов недропользования»
   — .../ai → AI-помощник недропользователя, поле ввода вопроса
   — .../erp/ → ERP с дашбордом и меню слева
   — .../erp/reports/stage/1 → PDF-отчёт по первому этапу

   СТОП. Напиши, что открылось по каждому пункту. Дальше идём только если все пять работают.

7. Вернись на вкладку 1. Найди в Railway второй сервис — с доменом
   well-343-karatube-production.up.railway.app. Это устаревший дубль сайта.
   Открой его → Settings → Delete Service.
   Если не уверен, что нашёл именно дубль (а не рабочий сервис из шага 1) — СТОП, спроси меня.

═══ ЧАСТЬ 2. Домен nanocem.app ═══

8. Вкладка 1, рабочий сервис → Settings → Networking → Public Networking → Custom Domain.
   Введи nanocem.app. Railway покажет две записи: CNAME (значение вида xxxxx.up.railway.app)
   и TXT для подтверждения владения.

   СТОП. Пришли мне оба значения текстом. Не меняй ничего в Vercel, пока я не подтвержу.

9. Вкладка 3 (проект well-343-karatube → Settings → Domains). Отвяжи от проекта домены
   nanocem.app и www.nanocem.app — кнопка Remove в строке домена.

   ВАЖНО: это не то же самое, что удалить домен из аккаунта. Не заходи в раздел
   Account/Team → Domains с целью Delete domain или Transfer out — там лежит сама регистрация
   домена, оплаченная до 10.07.2027. Нам нужно только отвязать домен от проекта.

10. Вкладка 4 (Domains → nanocem.app → DNS Records). Приведи зону к такому виду:
    — Удали записи типа ALIAS, которые указывают на vercel-dns: одну с пустым именем (@)
      и одну с именем * (звёздочка).
    — Добавь ALIAS: имя @, значение — CNAME-таргет из шага 8.
    — Добавь TXT: имя и значение ровно как показал Railway.
    — Добавь CNAME: имя www, значение — тот же таргет из шага 8.
    — Записи CAA не трогай, они должны остаться.

    СТОП. Пришли мне список записей, которые получились.

11. Вернись на вкладку 1, экран Custom Domain. Обновляй страницу и жди зелёной отметки о
    верификации домена — обычно 1–15 минут, иногда до получаса.

    Если через 30 минут отметки нет — СТОП, напиши мне «домен не верифицируется».
    Это будет значить, что ALIAS в Vercel DNS не резолвит внешние цели и нужен план Б.

12. Когда домен подтвердится — вкладка 5. Открой и проверь:
    — https://nanocem.app/ → главная сайта
    — https://nanocem.app/ai → AI-помощник
    — https://nanocem.app/erp/ → ERP
    — https://nanocem.app/stages.html → этапы, кнопка «Отчёт PDF» открывает PDF

    СТОП. Напиши итог по каждому пункту.

═══ ОТКАТ, если что-то пошло не так ═══

Вкладка 3 → Settings → Domains → Add Domain → nanocem.app. Vercel восстановит свои DNS-записи
автоматически, сайт поднимется на прежнем месте за несколько минут. Railway при этом можно
оставить как есть — он продолжит работать по адресу subsoil-ai-production.up.railway.app.
```

## Справочные данные

| Что | Значение |
|---|---|
| Репозиторий | `qazaqboss/well-343-karatube`, ветка `main` |
| Рабочий сервис Railway | тот, где домен `subsoil-ai-production.up.railway.app` |
| Сервис на удаление | `well-343-karatube-production` — дубль сайта |
| Переменные | `ANTHROPIC_API_KEY`, `DB_PATH=/data/erp.db` |
| Том | точка монтирования `/data` |
| Домен | `nanocem.app`, регистратор Vercel, оплачен до 10.07.2027 |
| Команда Vercel | `qazaqboss-projects`, проект `well-343-karatube` |

## Что появится после переезда

- `nanocem.app/` — сайт аналитики (работает и сейчас)
- `nanocem.app/ai` — AI-помощник (сейчас 404 на домене)
- `nanocem.app/erp/` — ERP (сейчас 404 на домене)
- `nanocem.app/erp/reports/stage/1..7` — PDF-отчёты по этапам

До переезда ссылки на AI и ERP со страниц сайта автоматически уводят на
`subsoil-ai-production.up.railway.app` — за это отвечает `public/backend.js`. После переезда он
определит, что бэкенд рядом, и оставит ссылки локальными. Удалять его не нужно.
