# 📊 KPI и контроль сроков (риск штрафов)

> Просрочка регуляторного срока = штраф. Управленческий учёт отслеживает дедлайны как KPI.

## Ключевые дедлайны

| Обязательство | Срок | Источник |
|---------------|------|----------|
| Проект разведки | 1 год с регистрации контракта | [[40-KONN-Art-134]] |
| Проект ПЭ | 3 месяца с решения | [[40-KONN-Art-136]] |
| Подготовительный период | ≤ 3 лет | [[40-KONN-Art-119]] |
| Авторнадзор | ежегодно | [[40-KONN-Art-142]] |
| Анализ разработки | раз в 3 года | [[40-KONN-Art-6]] |

## Светофор риска (для дашборда)

```python
def risk(days_left):
    if days_left > 90: return "🟢 низкий"
    if days_left > 30: return "🟡 средний"
    return "🔴 высокий"
```

## KPI этапа

- % выполнения проектных документов
- Дни до ближайшего дедлайна
- Отклонение бюджета (факт vs план)
- Замороженные платежи (паспорта не утверждены)
