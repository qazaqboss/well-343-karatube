# 💰 Центры затрат (cost centers)

> Каждый этап = центр затрат. Помогает планировать бюджет и считать факт/отклонение.

| Этап | Основные статьи затрат |
|------|------------------------|
| 1.Разведка | Сейсморазведка, поисковое бурение, проектирование, ОВВ/РООС |
| 2.Оценка | Оценочное бурение, ГИС/ГДИС, лаборатория, подсчёт запасов |
| 3.Гос.Баланс | Экспертиза ГКЗ, анализ разработки |
| 4.Подготовит. | Проект разработки, техпроект, обустройство |
| 5.Полномасшт. | Бурение добывающих, эксплуатация, пересчёт |
| 6.Ликвидация | Ликвидационные работы, рекультивация |
| 7.Сдача | Финальный отчёт, приёмка |

## Сквозные статьи

- **Обеспечение по ликвидации** ([[40-Order-27-NK|Приказ №27-н/к]]) — резервируется с этапа 1
- **Авторнадзор** — ежегодно, этапы 1, 2, 4, 5
- **Штрафы** — при просрочке (см. [[85.04-KPI-Deadlines]])

## Шаблон бюджета

Раздел 5.1 в `Shablon-Otchet-po-Etapu.pdf`: статья · план · факт · отклонение.
