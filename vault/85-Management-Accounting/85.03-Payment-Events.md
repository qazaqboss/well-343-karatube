# 🔒 Платёжные события (вехи)

## TL;DR

> Финальная оплата подрядчику **заблокирована до утверждения паспорта скважины МЭиПР**.
> В управленческом учёте это — условное обязательство (escrow).

## Вехи (учётные события)

| Веха | % | Учётное событие |
|------|---|-----------------|
| Мобилизация | 10% | Аванс выдан |
| Бурение завершено | 40% | Промежуточный акт, начисление |
| Испытания пройдены | 20% | Начисление по отчёту об испытании |
| Паспорт подан | 20% | Начисление |
| **Паспорт утверждён МЭиПР** | 10% | 🔓 Разблокировка финальной оплаты |

## Логика блокировки

```python
contract.final_payment.released = (well.passport_status == "approved_by_meminpr")
```

## Зачем для учёта

- До утверждения паспорта — **резерв** (не расход)
- После — расход признаётся, оплата проходит
- Просрочка паспорта → деньги «заморожены» → кассовый разрыв риск
