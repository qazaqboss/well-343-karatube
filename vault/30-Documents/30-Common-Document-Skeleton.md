# 🦴 Универсальный скелет базового проектного документа

> Любой 🟢 базовый проектный документ построен по одной схеме.

## Структура (6 разделов)

1. **Описание (цель документа)**
2. **Нормативная база** — список актов
3. **Что проектом предусматривается** — виды работ
4. **Что документ должен содержать** — детали
5. **Размер обеспечения по ликвидации** ([[40-Order-27-NK]])
6. **Мероприятия по охране недр и ООС**

## Фазы прохождения (стандартные 7)

I → II ([[40-EK-Art-68]]) → III (ОВВ/РООС) → IV (согласования) → V (экспертиза) → VI ([[50-TCKRR|ЦКРР]]) → VII (передача)

## Где меняется

- **Статья КОНН** (134 для разведки, 137 для разработки, 138 для ликвидации)
- **Состав требований**
- **Цепочка согласований**
- **Уведомительный vs экспертный** порядок
