# 📄 «Проект разведочных работ (оценочный этап)»

## Карточка

| Параметр | Значение |
|----------|----------|
| Тип | 🟢 Базовый проектный документ |
| Цель | Разведка и оценка обнаруженной залежи, обоснование ввода в разработку |
| Регулирование | [[40-KONN-Art-134]] + [[40-KONN-Art-135]] |
| ОВВ/РООС | [[40-EK-Art-67]] |

## Отличия от поискового этапа

Структура **почти идентична** [[20.01.01-Project-Document|поисковому проекту]], но:
- 📐 Задачи — **по оценке**, не по поиску
- 🛢️ Скважины — **оценочные**, не поисковые
- 🎯 Цель — обосновать **целесообразность ввода в разработку**

## Что предусматривается

- Сейсморазведка 3Д/2Д
- Обработка и интерпретация
- Бурение **оценочных** скважин

## Что должен содержать

Скелет тот же — [[30-Common-Document-Skeleton]] плюс:
- Задачи разведочных работ **по оценке**
- Объёмы и сроки **оценочных** работ
