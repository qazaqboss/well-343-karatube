# 📄 «Проект ликвидации последствий разведки УВ»

## Карточка

| Параметр | Значение |
|----------|----------|
| Регулирование | [[40-KONN-Art-138]] (изм. 10.06.2025) |
| ОВВ/РООС | [[40-EK-Art-67]] |
| Триггер | Завершение разведки + необходимость ликвидации |

## Когда применяется

- Скважины не перспективны → ликвидировать
- Объекты разведки больше не нужны
- Часть площади возвращается

## Нормативная база

- [[40-KONN-Art-138]] (изм. 10.06.2025)
- [[40-EPRKIN-Overview]]
- «Методические рекомендации по составлению проектов ликвидации при разведке и добыче УВ»
- [[40-ME-Order-200]]
- [[40-EK-Art-67]]
- [[40-Order-27-NK]] — обеспечение по ликвидации

## Что должен содержать

1. Технология **демонтажа, вывоза и захоронения** оборудования
2. Скважины разных категорий и назначения, **рекультивация** земельных участков
3. Объёмы ликвидации в зависимости от **банковского обеспечения**

## Фазы (I-V)

1. Заявление по [[40-EK-Art-68]]
2. ОВВ/РООС
3. Согласование (см. [[10.05-Regulatory-Map]])
4. Защита и экспертиза
5. Передача оператору

> ⚠️ При сложном проекте — нужен **обновлённый контракт** ([[10.03-Contract-Complexity]]).
