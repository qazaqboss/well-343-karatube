# ⚠️ Этап 2 — Типовые ошибки

## Ошибка 1: Пропустили срок проекта ПЭ

**Симптом:** 3 месяца со дня решения прошли, проекта нет.
**Решение:** Триггер при принятии решения о ПЭ.

## Ошибка 2: Не выявили признаки сложности

**Симптом:** Проект сложный, но обновление контракта не запросили.
**Решение:** Чек-лист критериев сложности на каждой защите ([[10.03-Contract-Complexity]]).

## Ошибка 3: Очистные не запроектированы при H₂S

**Симптом:** В газе > 14,1386 мг/м³ H₂S или серных соединений, очистные не предусмотрены.
**Решение:** Обязательный пункт чек-листа проекта ПЭ.

## Ошибка 4: Нет статической модели залежи

**Симптом:** Проект ПЭ без геолого-промысловой модели.
**Решение:** Обязательно для каждого проекта ПЭ.

## Ошибка 5: Скважины в ПЭ не пронумерованы

**Симптом:** В проекте «несколько скважин» без номеров.
**Решение:** Требование — **количество и номера** всех участвующих скважин.

## Ошибка 6: Перевод запасов C₂→C₁ без комплекса исследований

**Симптом:** Перевели категории без полного комплекса по [[40-MIIR-Order-71]].
**Решение:** Только при наличии полного комплекса исследований.
