# 💼 Этап 2 — Реальные кейсы

## Кейс 1: Положительная разведка → переход к оценке

**Контекст:** На этапе 1 пробурено 3 поисковые скважины, в 2 из них — положительный результат.

**Решение оператора:**
1. Подготовлен **оценочный проект разведки** для 2 перспективных участков
2. По 1 неперспективной скважине — **проект ликвидации последствий разведки**
3. По 2 перспективным — оценочные скважины + далее **оперативный подсчёт**

## Кейс 2: Решение о пробной эксплуатации

**Контекст:** Оперативный подсчёт показал значительные запасы.

**Тайминг:**
| Дата | Событие |
|------|---------|
| 01.06.2025 | Оперативный подсчёт защищён в ГКЗ |
| 15.06.2025 | Решение оператора о пробной эксплуатации |
| 15.09.2025 | **Дедлайн** проекта ПЭ (3 месяца) |
| 15.10.2025 | Заявление по ст. 68 ЭК |
| 01.01.2026 | ОВВ/РООС готов |

| 15.04.2026 | Передача оператору |
| 01.05.2026 | Старт пробной эксплуатации |

## Кейс 3: Выявлены критерии сложности

**Контекст:** При оценочном бурении выяснилось: пластовое давление аномально высокое.

**Действия:**
1. STOP проектных работ
2. Документально зафиксировать критерии
3. Подать заявление в МЭиПР на обновление контракта
4. Получить дополнение к контракту
5. Только после этого — продолжать ОВВ/РООС
6. Срок этапа теперь — 9+6+3 лет вместо 6+3+3
