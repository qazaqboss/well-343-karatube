# ⚠️ Этап 7 — Типовые ошибки

## Ошибка 1: Не приложены все 16 документов

**Симптом:** Окончательный отчёт без какого-то из приложений.
**Решение:** Чек-лист всех 16 пунктов перед сдачей.

## Ошибка 2: Не уведомили МЭ о завершении ликвидации

**Симптом:** Ликвидация завершена, но извещение не отправлено.
**Решение:** Триггер сразу по завершению работ.

## Ошибка 3: Отчёт без рецензии МД

**Симптом:** Отчёт отправлен в фонды без рецензии Совета МД.
**Решение:** Сначала МД → рецензия → потом фонды.
