# ✅ Этап 1 — Финальный чек-лист

## Перед стартом

- [ ] Контракт зарегистрирован, есть дата регистрации
- [ ] Назначен ответственный за проект разведки
- [ ] Выбран подрядчик-проектировщик
- [ ] Уведомлены [[60.02-Drilling-Contractor]] и [[60.03-Geophysical-Contractor]]

## Состав проектного документа

- [ ] Объёмы и значимость исторических данных
- [ ] Задачи разведочных работ по поиску
- [ ] Методика полевых геолого-геофизических исследований
- [ ] Кол-во, местоположение и проектные глубины скважин
- [ ] Интервалы отбора керна и шлама
- [ ] Порядок испытания нефтегазоносных горизонтов
- [ ] Комплекс ГИС в открытом стволе и колонне
- [ ] Комплекс ГДИС
- [ ] Отбор и лабораторное изучение проб
- [ ] Мероприятия по охране недр и ООС
- [ ] Объёмы и сроки работ
- [ ] Инвестиции и эффективность
- [ ] Прогнозный дебит по каждой скважине
- [ ] **Размер обеспечения по ликвидации** ([[40-Order-27-NK]])

## Прохождение фаз

- [ ] **I:** Уведомление в МЭиПР отправлено
