# ⚠️ Этап 3 — Типовые ошибки

## Ошибка 1: Анализ разработки делается реже 1 раза в 3 года

**Симптом:** Между анализами 4-5 лет.
**Решение:** Триггер `next_due = last_analysis + 3 years - 90 days` (запас на подготовку).

## Ошибка 2: КЗН не обоснован

**Симптом:** Произвольный КЗН без обоснования через аналогию с принятыми ГКЗ.
**Решение:** Обязательное обоснование по аналогии с региональными месторождениями.

## Ошибка 3: Не сдали отчёт в один из фондов

**Симптом:** Сдали в МД, забыли НГС (или наоборот).
**Решение:** Чек-лист обязательной сдачи в **оба** фонда.
