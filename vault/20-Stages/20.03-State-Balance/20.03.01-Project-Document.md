# 📄 «Подсчёт запасов нефти и растворённого газа» (Гос.Баланс)

## Карточка

| Параметр | Значение |
|----------|----------|
| Тип | 🟦 Геологический отчёт |
| Срок составления | 3 месяца со дня решения оператора |
| Орган защиты | [[50-GKZ]] |
| Сдача в фонды | МД + [[50-NGS]] |

## Отличия от оперативного подсчёта

| | Оперативный ([[20.02.03-Operativnyy-Podschet|2.3]]) | Гос.Баланс (здесь) |
|---|---|---|
| Когда | Этап 2 | Этап 3 |
| Цель | Первичная оценка | Официальный учёт |
| Защита в ГКЗ | Да | **Да, с протоколом для баланса** |
| Категории запасов | Низкие | Подтверждённые |

## Нормативная база

- [[40-MIIR-Order-419]] (изм. 25.08.2020)
- [[40-MIIR-Order-71]] (02.02.2023)

## Содержание

Структура та же, что у оперативного — см. [[30-Common-Geological-Report-Content]].

> 💡 КЗН (коэффициент нефтегазоносности) принимается **по аналогии** с ранее принятыми ГКЗ РК коэффициентами числящихся на балансе запасов месторождений данного региона.
