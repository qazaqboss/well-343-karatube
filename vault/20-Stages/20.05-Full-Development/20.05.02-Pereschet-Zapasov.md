# 📄 «Пересчёт запасов нефти и растворённого газа»

## Карточка

| Параметр | Значение |
|----------|----------|
| Тип | 🟦 Геологический отчёт |
| Триггер | **δ запасов > 20%** от утверждённых ГКЗ |
| Орган | [[50-GKZ]] |

## Триггер

> Осуществляется, когда запасы залежи **после разбуривания изменились более чем на 20%** по сравнению с ранее утверждёнными ГКЗ РК запасами.

```python
delta_percent = abs(new_reserves - approved_reserves) / approved_reserves
if delta_percent > 0.20:
    trigger_recalculation()
```

## ⚠️ Блокирующее событие

> 🔒 Утверждение нельзя проводить до защиты в ГКЗ.

См. AI-обработку: [[FAQ-Reserve-Delta-20]].
