# ⚠️ Этап 5 — Типовые ошибки

## Ошибка 1: Не отследили δ > 20%

**Симптом:** Накопились данные на 25% изменения запасов, пересчёт не сделан.
**Решение:** Автомониторинг δ, при превышении — блок утверждений.

## Ошибка 2: Контракт без обязательств для крупного месторождения

**Симптом:** Запасы > 100 млн т нефти / 50 млрд м³ газа, но в контракте нет одного из 5 обязательств п.7 ст.119.
**Решение:** Проверка при подписании контракта + при пересчёте.

## Ошибка 3: Продление периода добычи без обоснования

**Симптом:** Подали на продление, но без подтверждённых запасов.
**Решение:** Продление только при положительном заключении гос.экспертизы недр.
