# 💼 Этап 4 — Примеры

## Кейс 1: Стандартный переход от гос.баланса к разработке

**Контекст:** Запасы в гос.балансе с 01.12.2025.

**Тайминг:**
| Дата | Событие |
|------|---------|
| 01.12.2025 | Запасы в гос.балансе |
| 01.01.2026 | Старт подготовительного периода |
| 01.06.2026 | Проект разработки готов |
| 01.12.2026 | Согласования получены |
| 01.01.2027 | Проект разработки утверждён |
| 01.07.2027 | Техпроект скважин готов |
| 01.01.2028 | Старт бурения добывающих |
| 01.12.2028 | **Дедлайн** подготовительного периода (3 года) |
| 01.01.2029 | Старт этапа 5 (полномасштабная) |

## Кейс 2: Перевод запасов C₂ → C₁

**Контекст:** В процессе бурения опережающе-добывающих скважин — данные подтверждают переход в более высокую категорию.

**Действия:**
1. Зафиксировать новые данные
2. Подготовить отчёт по переводу запасов
3. Защитить в ГКЗ
4. Сдать в МД и НГС
5. Обновить базу запасов
