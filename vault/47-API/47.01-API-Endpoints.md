# 🔌 REST API

## Чат / AI
| Метод | Путь | Назначение |
|-------|------|-----------|
| POST | `/ask` | вопрос → RAG-ответ + источники + предложение документа |

## Отчёты (генерация PDF)
| Метод | Путь | Возвращает |
|-------|------|-----------|
| GET | `/reports/portfolio` | сводка портфеля |
| GET | `/reports/deadlines` | реестр дедлайнов/рисков |
| GET | `/reports/payments` | статус паспортов и платежей |
| GET | `/reports/stage/{n}` | отчёт по этапу N |
| POST | `/reports/doc` | конкретный проектный документ |
| POST | `/reports/passport/{well}` | паспорт скважины |
| POST | `/reports/welltest/{well}` | отчёт об испытании (5 объектов) |

## CRUD
| Метод | Путь |
|-------|------|
| GET/POST | `/contracts`, `/wells`, `/documents`, `/contractors` |
| GET | `/contracts/{id}/stages` |
| GET | `/wells/{id}/passport` |
