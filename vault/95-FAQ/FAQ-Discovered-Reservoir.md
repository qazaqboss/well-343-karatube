# ❓ На разведке нашли залежь

## Запрос пользователя

> Поисковая скважина дала приток. Что делать?

## Ответ

Это триггер перехода с этапа 1 на **этап 2 (Оценка)**.

**Минимум 1 документ — оценочный проект:**
- Подготовить **[[20.02.01-Project-Razvedki-Otsenochnyy|«Проект разведочных работ (оценочный этап)»]]** по ст. 134-135 КОНН
- Задачи переориентируются с поиска на оценку
- Бурение оценочных скважин

**Возможно ещё 3 документа этапа 2:**
- [[20.02.02-Project-Likvidatsii-Razvedki|Проект ликвидации последствий разведки]] — для неперспективных скважин
- [[20.02.03-Operativnyy-Podschet|Оперативный подсчёт запасов]] — первичная оценка
- [[20.02.04-Project-Probnoy-Ekspl|Проект пробной эксплуатации]] — если будет пробная добыча (**срок 3 месяца** с решения!)

**⚠️ Проверить признаки сложности:**
- Глубина / давление / H₂S / морская локация
- Если есть — обновить контракт перед фазой III ([[10.03-Contract-Complexity]])
