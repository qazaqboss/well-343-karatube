# ❓ Возврат части участка

## Запрос пользователя

> Как вернуть часть контрактной территории?

## Ответ

Возврат регулируется ст. 114 КОНН — оператор **вправе в любое время** до истечения периода уменьшить участок недр через возврат части.

**Шаги:**

1. **Этап 6: Проект ликвидации** для возвращаемой части
   - По [[40-KONN-Art-138]]
   - С ОВВ/РООС ([[40-EK-Art-9]] + ст. 67)
   - Полная цепочка согласований (5-7 органов)

2. **Ликвидационные работы**
   - Консервация / ликвидация скважин по [[40-ME-Order-200]]
   - Рекультивация земель

3. **Этап 7: Сдача**
   - **Окончательный отчёт о ГРР на возвращаемой территории** ([[20.07.01-Final-Report]])
   - 16 обязательных приложений
   - Через МД (Совет МД) + сдача в фонды
   - Приёмка комиссией → **акт ликвидации**

См. [[20.06.00-Overview]] · [[20.07.00-Overview]]
