# ❓ Паспорт скважины

## Запрос пользователя

> Зачем нужен паспорт скважины?

## Ответ

**Паспорт скважины** — главный документ по каждой пробуренной скважине. Это **точка истины** в системе.

**Что в паспорте:**
- Координаты, глубина
- Конструкция (трубы, колонны)
- Литология
- Результаты ГИС и ГДИС
- Дебиты при опробовании
- Категория (поисковая / оценочная / добывающая / нагнетательная / ликвидированная)
- Связь с проектным документом

**Жизненный цикл:**

```
Бурение → 90-дневный цикл → Паспорт → Подача в МЭиПР → Утверждение → Реестр
```

**⚠️ Финансовая привязка:**
> Финальная оплата подрядчику разблокируется только после **утверждения** паспорта МЭиПР.

**Где применяется:**
- Этапы 1, 2, 4, 5 (бурение)
- Этап 6 (ликвидация скважин)
- Этап 7 (паспорта в финальном отчёте)
