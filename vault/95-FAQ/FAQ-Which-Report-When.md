# ❓ Какой отчёт/паспорт когда делать?

## Запрос пользователя

> На каком этапе какой документ мне нужен?

## Краткий ответ

Зависит от этапа. Полная карта — [[35.00-Report-Catalog]]. Кратко:

- **Пробурили скважину** (любой этап) → **паспорт скважины** + **отчёт об испытании**
- **Нашли залежь** (этап 2) → оперативный подсчёт + проект ПЭ
- **Готовите гос.баланс** (этап 3) → подсчёт запасов
- **Запасы ±20%** (этап 5) → пересчёт запасов
- **Уходите с участка** (этап 6-7) → проект ликвидации + окончательный отчёт
- **Любой этап, для руководства** → отчёт по этапу (с управленческим учётом)

## Готовые шаблоны

- Паспорт скважины · Отчёт об испытании · Отчёт по этапу — в папке `PDF/`
