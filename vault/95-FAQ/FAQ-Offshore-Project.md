# ❓ Особенности морских проектов

## Запрос пользователя

> Чем отличается морской проект от сухопутного?

## Ответ

**Главное:** морские проекты — **исключение** из уведомительного порядка ([[40-KONN-Art-113]]).

**Отличия:**

| | Сухопутный | Морской |
|---|------------|---------|
| Подача проекта разведки | Уведомительно | **Госэкспертиза** |
| Согласование | Стандартная цепочка | + Лесная инспекция + Жайык-Каспий |
| Промбезопасность | [[40-ME-Order-355\|Приказ №355]] | [[40-ME-Order-356\|Приказ №356]] (от 30.12.2014, изм. 04.08.2023) |
| Ликвидация | Стандартная | + усиленные требования по ООС |

**Дополнительные органы:**
- [[50-Forestry-Inspection]] — Территориальная инспекция лесного хозяйства
- [[50-ZhaiykKaspii]] — Жайык-Каспийская бассейновая инспекция
