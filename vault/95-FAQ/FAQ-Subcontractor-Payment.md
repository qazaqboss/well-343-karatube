# ❓ Платежи субподрядчикам

## Запрос пользователя

> Как платить субподрядчику бурового подрядчика (тампонажному)?

## Ответ

Тампонажный (или любой суб-) подрядчик — **второй уровень**. Платит ему **основной подрядчик** (буровой), а не оператор напрямую.

**Цепочка платежей:**

```
Оператор → Буровой подрядчик → Тампонажный подрядчик
```

**Связь с паспортом скважины:**
- Оператор задерживает финальный платёж буровому → буровой задерживает тампонажному
- Все привязано к утверждению паспорта МЭиПР

**Что прописать в субподряде:**
1. Платёжные вехи (зеркало основного договора)
2. Обязанность передать данные/документы основному подрядчику
3. Срок передачи данных
