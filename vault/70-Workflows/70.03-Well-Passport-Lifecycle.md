# 📄 Паспорт скважины — точка истины

## TL;DR

**Паспорт скважины** — главный документ по каждой пробуренной скважине. **Без утверждённого паспорта оплата подрядчику заблокирована.**

## Жизненный цикл

```mermaid
stateDiagram-v2
    [*] --> Bureniye
    Bureniye --> Testing: бурение завершено
    Testing --> Data: 90-дневный цикл
    Data --> Draft: данные собраны
    Draft --> Submitted: оператор подал в МЭиПР
    Submitted --> UnderReview: МЭиПР проверяет
    UnderReview --> Approved: ✅
    UnderReview --> Rejected: ❌
    Rejected --> Draft: исправить и переподать
    Approved --> Registry: внесён в реестр МЭиПР
    Registry --> [*]: 💰 финальная оплата разблокирована
```

## Что в паспорте

- Координаты, глубина
- Конструкция (трубы, колонны)
- Литология
- Результаты ГИС и ГДИС
- Дебиты при опробовании
- Категория (поисковая / оценочная / добывающая / нагнетательная / ликвидированная)
- Связь с проектным документом
