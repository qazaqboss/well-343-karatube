# ⏰ Штрафы и дедлайны

## Общая идея

> Регуляторика РК устанавливает **жёсткие сроки**. Просрочка = штрафы оператору, которые **перетекают** на подрядчиков через договоры.

## Главные дедлайны

| Срок | Источник |
|------|----------|
| 1 год — проект разведки с регистрации контракта | [[40-KONN-Art-134]] |
| 3 месяца — проект пробной эксплуатации | [[40-KONN-Art-136]] |
| 3 месяца — подсчёт запасов | КОНН |
| **3 года** — подготовительный период | [[40-KONN-Art-119]] |
| Ежегодно — авторнадзор | [[40-KONN-Art-142]] |
| Раз в 3 года — анализ разработки | [[40-KONN-Art-6]] |
| 25 лет — период добычи (45 крупные) | [[40-KONN-Art-119]] |

## Типичные штрафы (общая логика)

- **Просрочка отчётности** — административные штрафы
- **Несоблюдение экологических требований** — крупные штрафы + остановка работ
- **Несвоевременная ликвидация** — взыскание обеспечения

## Триггеры в системе

```python
# Пример триггера для проекта разведки
if days_since_contract_registration > 330:  # 30 дней запаса
    notify("⚠️ До дедлайна проекта разведки 35 дней")

if days_since_last_supervision > 350:
    notify("⚠️ Авторнадзор за прошлый год не подан")
```
