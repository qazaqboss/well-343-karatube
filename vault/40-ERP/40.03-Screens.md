# 🖥️ 6 экранов системы

| Экран | Назначение | Ключевые кнопки |
|-------|-----------|-----------------|
| **Dashboard** | сводка портфеля, дедлайны, риски | «Портфель», «Реестр дедлайнов», «Статус паспортов» |
| **Licenses** (список) | все контракты/лицензии | «+ Контракт», фильтр по этапу |
| **License Detail** | один контракт, его этапы | «Скачать отчёт по этапу», «Документы этапа» |
| **Calendar** | дедлайны, авторнадзор, анализ разработки | «Экспорт календаря» |
| **Well Detail** | скважина, объекты, паспорт | «Сформировать паспорт», «Отчёт об испытании» |
| **AI Assistant** | чат-бот (RAG + генерация) | «Скачать отчёт/паспорт» в ответах |

## Дизайн
Стиль: Linear / Stripe Dashboard — чисто, данные в центре, минимализм. Cmd+K — палитра команд.
