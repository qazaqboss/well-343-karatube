# 🗃️ Модель данных

## Ключевые сущности (DocTypes)

| DocType | Поля (ключевые) | Связи |
|---------|-----------------|-------|
| **Contract** (Контракт) | №, дата регистрации, территория, тип (обычный/сложный), срок | → Stage, Well |
| **Stage** (Этап) | номер 1-7, статус, даты, бюджет | → Contract, Document |
| **Document** (Проектный документ) | тип, статус, фаза I-VII, орган, дедлайн | → Stage |
| **Well** (Скважина) | №, координаты, забой, категория, статус паспорта | → Contract, TestObject |
| **TestObject** (Объект испытания) | №, интервал, флюид, дебит, давления | → Well |
| **Passport** (Паспорт скважины) | статус (подан/утверждён), реестр.№, дата | → Well |
| **Contractor** (Подрядчик) | тип (буровой/геофиз/тампонаж), договор | → PaymentMilestone |
| **PaymentMilestone** (Платёжная веха) | %, триггер, статус, блокировка | → Contractor, Passport |
| **Authority** (Госорган) | название, уровень, функции | → Document |
| **Deadline** (Дедлайн) | обязательство, дата, риск | → Stage |
| **Reserve** (Запасы) | категория C₂/C₁/B/A, объём, δ | → Well |

## Бизнес-правило (блокировка оплаты)
```python
PaymentMilestone.released = (Passport.status == "approved_by_meminpr")
```
