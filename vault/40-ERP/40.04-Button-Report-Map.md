# 🔘 Карта «кнопка → отчёт»

> Главное требование: **каждая кнопка выдаёт документ**. Полная привязка.

| Экран | Кнопка | Действие / эндпоинт | Результат (PDF) |
|-------|--------|---------------------|-----------------|
| Dashboard | Портфель лицензий | `GET /reports/portfolio` | Сводка по контрактам |
| Dashboard | Реестр дедлайнов | `GET /reports/deadlines` | Дедлайны + риски |
| Dashboard | Статус паспортов | `GET /reports/payments` | Паспорта + блок оплат |
| License Detail | Отчёт по этапу N | `GET /reports/stage/{n}` | Отчёт по этапу (+учёт) |
| License Detail | Документ этапа | `POST /reports/doc` | Конкретный проект/отчёт |
| Well Detail | Сформировать паспорт | `POST /reports/passport/{well}` | Паспорт скважины |
| Well Detail | Отчёт об испытании | `POST /reports/welltest/{well}` | Отчёт (5 объектов) |
| AI Assistant | Скачать (в ответе) | `POST /reports/{kind}` | Любой из выше |

## Серверная генерация
Все отчёты собирает один сервис на reportlab (см. `make_*_reports.py`), параметризованный
данными из PostgreSQL. Шаблоны — брендируются под недропользователя («Ваша компания» → реальное имя).
