# 🏛️ Государственные органы — MOC

## Иерархия

```mermaid
flowchart TB
    GOVT[Правительство РК]
    GOVT --> ME[МЭиПР РК]
    GOVT --> MCHS[МЧС РК]
    GOVT --> MZ[МЗ РК]
    GOVT --> AKIM[Местные исполн. органы]
    ME --> KOM_EKO[Комитет эко-регулирования]
    ME --> KOM_GEO[Комитет геологии]
    KOM_GEO --> GKZ[ГКЗ РК]
    KOM_GEO --> NGS[АО НГС]
    KOM_GEO --> MD_ZAP[МД Запказнедра]
    KOM_GEO --> MD_YUZ[МД Южказнедра]
    ME --> TCKRR[ЦКРР]
    MCHS --> KOM_PROM[Комитет промбезопасности]
    MZ --> KOM_SAN[Комитет сан-эпидконтроля]
    AKIM --> ZEM[Управление земельных отношений]
    AKIM --> LES[Лесная инспекция]
    AKIM --> KASP[Жайык-Каспий]
```

## По функции

### Кто согласовывает базовые проекты?

```mermaid
flowchart LR
    DOC[Проект] --> NOTIF[Уведомление в МЭиПР]
    NOTIF --> EKO[Эко-регулирование]
    NOTIF --> ZEM[Земельные отношения]
    NOTIF --> SAN[Сан-эпид]
    NOTIF --> PROM[Промбезопасность]
    NOTIF --> MD[МД]
    EKO --> TCKRR[ЦКРР]
    TCKRR --> OPER[Оператор]
```

### Кто согласовывает геологические отчёты?

```mermaid
flowchart LR
    GEO[Геол. отчёт] --> GKZ[ГКЗ - экспертиза]
    GKZ --> ZASCH[Защита]
    ZASCH --> FUNDS{Сдача в фонды}
    FUNDS --> MD[МД]
    FUNDS --> NGS[АО НГС]
    FUNDS --> OPER[Оператор]
```

### Кто согласовывает ликвидационные проекты?

```mermaid
flowchart LR
    LIQ[Проект ликвидации] --> ZEM[Земельные]
    LIQ --> PROM[МЧС - промбезопасность]
    LIQ --> SAN[МЗ - сан-эпид]
    LIQ --> MD[МД]
    LIQ --> EKO[Эко-департамент]
    LIQ -.->|морские| LES[Лесная инспекция]
    LIQ -.->|морские| KASP[Жайык-Каспий]
```
