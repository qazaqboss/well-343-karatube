# 📚 Глоссарий

> Атомарные определения. Линки — на полные карточки.

## Документы

- **Базовый проектный документ** — главный документ этапа (🟢). См. [[04-Documents-MOC]].
- **Технический проектный документ** — детали строительства (🟡).
- **Геологический отчёт** — отчёт о запасах и геологии (🟦).
- **ОВВ** — Отчёт о Возможных Воздействиях.
- **РООС** — Раздел Охраны Окружающей Среды.
- **Авторский надзор** — контроль соответствия фактических работ проектным.

## Структуры

- **Залежь** — естественное локальное скопление УВ.
- **Совокупность залежей** — несколько залежей в одном объекте.
- **Месторождение** — совокупность залежей, экономически целесообразных к разработке.
- **Контрактная территория** — участок недр, переданный оператору.
- **Горный отвод** — фактически закреплённый участок добычи.

## Скважины

- **Поисковая** — для поиска залежей (этап 1).
- **Оценочная** — для оценки обнаруженной залежи (этап 2).
- **Опережающе-добывающая** — добывающая, пробуренная до полномасштабной разработки.
- **Добывающая** — основная (этапы 4, 5).
- **Нагнетательная** — для закачки агента.
- **Контрольная** — для мониторинга.

## Запасы (категории по [[40-MIIR-Order-71]])

```mermaid
flowchart LR
    C2[C₂ - предварительно] -->|разбуривание| C1[C₁ - разведано]
    C1 -->|уплотн. сетка| B[B - доразведано]
    B -->|детально| A[A - детально]
```

- **A** — детально разбуренные
- **B** — разбуренные с уплотнённой сеткой
- **C₁** — разведанные
- **C₂** — предварительно оценённые

Перевод между категориями — см. [[70.04-Reserve-Reclassification]].
