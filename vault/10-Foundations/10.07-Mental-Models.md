# 🧠 Ментальные модели

> Аналогии, которые AI и человек используют для быстрого понимания.

## Модель 1: Жизненный цикл недропользования = аренда склада

> Государство сдаёт склад → ты входишь → ищешь товар → продаёшь товар → освобождаешь склад → возвращаешь ключи

| Реальность | Аналогия |
|------------|----------|
| Контракт | Договор аренды |
| Разведка | Осматриваешь склад |
| Оценка | Проверяешь, что внутри |
| Гос.Баланс | Записываешь в инвентарь |
| Подготовительный | Готовишь оборудование |
| Полномасштабная | Работаешь |
| Ликвидация | Прибираешься |
| Сдача | Возвращаешь ключи |

## Модель 2: Платёжная блокировка = эскроу

> Подрядчик не получает оплату пока МЭиПР не утвердит документы.
> Это **эскроу-аккаунт** — деньги заморожены до выполнения условия.

См. [[70.01-Payment-Milestones]].

## Модель 3: Категории запасов = уровни доверия

```
C₂ → "я думаю, тут есть нефть"
C₁ → "я её видел в керне"
B  → "я её добывал, и есть данные"
A  → "я её добываю по плотной сетке скважин"
```

См. [[70.04-Reserve-Reclassification]].

## Модель 4: Авторнадзор = ежегодная инспекция машины

> Каждый год машина проходит ТО, чтобы катиться дальше.
> Так же проект каждый год проходит «ТО» через авторнадзор.

См. [[70.05-Author-Supervision-Cycle]].

## Модель 5: Сложность контракта = красный флаг

> Сложность — это **STOP-сигнал**. Не игнорировать, не работать дальше.

См. [[10.03-Contract-Complexity]].

## Модель 6: ОВВ vs РООС = страховой полис

> **ОВВ** — отдельный полис (полное страхование экологии)
> **РООС** — раздел в общем полисе (базовое покрытие)

МЭиПР решает, какой тип нужен на основе [[40-EK-Art-68|заявления о намечаемой деятельности]].

## Модель 7: Каскад согласований = эстафета

```
Уведомление → Заявление → ОВВ/РООС → Эко → Экспертиза → ЦКРР → Передача
   ⬆           ⬆          ⬆          ⬆      ⬆            ⬆       ⬆
   палочку передаёшь по цепочке. Уронишь — назад на старт.
```
