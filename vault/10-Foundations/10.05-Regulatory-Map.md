# 🗺️ Карта согласований

## TL;DR

Каждый проектный документ проходит **до 7 фаз** через разные органы. Это карта.

## Полная цепочка для базового проекта

```mermaid
flowchart TB
    OPER[👷 Оператор готовит документ] --> NOTIF[I. Уведомление]
    NOTIF --> MEMINPR[МЭиПР РК]
    MEMINPR --> DECISION{Нужен ОВВ/РООС?}
    DECISION -->|Да| OVVS[II-III. ОВВ/РООС]
    DECISION -->|Нет| BYPASS[Раздел в проекте]
    OVVS --> KOORD[IV. Согласования]

    KOORD --> EKO[Эко-департамент]
    KOORD --> ZEM[Земельные отношения]
    KOORD --> SAN[Сан-эпид. контроль]
    KOORD --> PROM[Промбезопасность]
    KOORD --> LES[Лесное хоз-во<br/>морские]
    KOORD --> KASP[Жайык-Каспий<br/>морские]

    EKO --> EXP[V. Независимая экспертиза]
    ZEM --> EXP
    SAN --> EXP
    PROM --> EXP
    EXP --> TCKRR[VI. Защита в ЦКРР]
    TCKRR --> FINAL[VII. Передача оператору]
```

## Для геологических отчётов

```mermaid
flowchart LR
    GEO[Геолог. отчёт] --> EXPERT[Эксперт ГКЗ]
    EXPERT --> ZASCH[Защита в ГКЗ]
    ZASCH --> PROTOKOL[Протокол ГКЗ]
    PROTOKOL --> FUNDS[МД + НГС]
    FUNDS --> OPER[Оператору]
```

## По типам документов

| Документ | Главный путь | Главные органы |
|----------|--------------|----------------|
| Базовый проект | Уведомительно + ЦКРР | МЭиПР, эко-департ, ЦКРР |
| ОВВ/РООС | Незав. экспертиза | Эко-департ + ЦКРР |
| Геол. отчёт | Защита в ГКЗ + фонды | ГКЗ, МД, НГС |
| Авторнадзор | Уведомительно | МЭиПР |
| Ликвидация | Полная цепочка | МЭиПР + МЧС + МЗ + эко |
| Финальный отчёт | Защита МД + фонды | МД + НГС |
