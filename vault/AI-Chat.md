## ⚙️ Установка (один раз)

```bash
# 1. Перейди в папку vault'а
cd "/путь/к/vault"

# 2. Создай .env с API ключом
cp .env.example .env
# Открой .env и вставь ключ: ANTHROPIC_API_KEY=sk-ant-...
# Получить ключ: https://console.anthropic.com/keys

# 3. Запусти (первый раз установит зависимости автоматически)
./start.sh --watch
```

## 📁 Что умеет помощник

- **7 этапов недропользования** — все документы, сроки, госорганы
- **Законодательство** — КОНН РК, ЭК РК, ЕПРКИН + подзаконные акты
- **Расчёт сроков** — «у вас осталось X дней до дедлайна»
- **Роли** — ответы для оператора, подрядчика, юриста
- **Триггеры** — δ запасов >20%, сложный проект, ликвидация
- **Платёжные вехи** — когда и за что получает оплату подрядчик
- **Госорганы** — кто что согласовывает (МЭиПР, ГКЗ, ЦКРР, МД, НГС...)
