# 🗄️ Структура RAG knowledge base

## Технический стек (рекомендация)

```
- Embeddings: text-embedding-3-large или multilingual-e5-large
- Vector DB: pgvector / Pinecone / Weaviate
- Search: гибридный (vector + BM25)
- Reranker: cohere-rerank или crossencoder
```

## Подготовка vault → vector DB

```python
from pathlib import Path
import json

documents = []
for md_file in Path("Subsoil-Vault").rglob("*.md"):
    if md_file.parent.name in ["80-Templates"]:
        continue  # шаблоны не нужны
    
    content = md_file.read_text()
    
    # Извлекаем frontmatter
    metadata = parse_frontmatter(content)
    body = strip_frontmatter(content)
    
    # Чанкуем по 512 токенов с overlap 50
    chunks = chunk(body, size=512, overlap=50)
    
    for i, chunk_text in enumerate(chunks):
        documents.append({
            "id": f"{md_file.stem}__chunk_{i}",
            "file_path": str(md_file.relative_to("Subsoil-Vault")),
            "title": metadata.get("title"),
            "tags": metadata.get("tags", []),
            "stage": metadata.get("stage"),
            "content": chunk_text
        })

# Эмбеддинги + загрузка в vector DB
```

## Metadata-фильтры

При запросе использовать metadata-фильтры:

```python
# Если в запросе явно упомянут этап
if "этап 5" in user_query or "полномасштабная" in user_query:
    filter = {"stage": "05"}

# Если упомянута роль
if any(word in user_query for word in ["буровой", "подрядчик"]):
    filter = {"tags": "role/drilling"}
```

## Гибридный поиск

```python
def hybrid_search(query, k=10):
    # 1. Vector search
    vec_results = vector_search(query, k=k*2)
    
    # 2. BM25
    bm25_results = bm25_search(query, k=k*2)
    
    # 3. Объединение через RRF (Reciprocal Rank Fusion)
    combined = reciprocal_rank_fusion(vec_results, bm25_results)
    
    # 4. Reranking
    final = rerank(query, combined, top_k=k)
    
    return final
```
