# 🔌 Путь A/B: Чат с вольтом без кода

> Запустить «бота по вольту» прямо в Obsidian за 10 минут — двумя плагинами. Это **RAG из коробки**: плагин сам индексирует заметки и отвечает на их основе.

## Путь A — Облачный (быстрее всего)

### Вариант 1: Smart Connections

Самый популярный RAG-плагин для Obsidian. Чат с вольтом + поиск связанных заметок.

**Шаги:**
1. Obsidian → Settings → Community plugins → Browse → **«Smart Connections»** → Install → Enable
2. В настройках плагина указать модель: OpenAI / Claude / Gemini / локальная
3. Плагин **проиндексирует** вольт (создаст эмбеддинги) — дождаться завершения
4. Открыть Smart Chat → задавать вопросы по вольту

**Плюсы:** бесплатное ядро, любая модель, работает офлайн с локальной моделью, эмбеддинги хранятся локально.

### Вариант 2: Copilot for Obsidian

Более «ассистентский» плагин: чат, Vault QA, работа с проектами, команды.

**Шаги:**
1. Community plugins → Browse → **«Copilot»** → Install → Enable
2. Вставить свой API-ключ (OpenAI / Anthropic) в настройки
3. Включить **Vault QA mode** — режим вопрос-ответ по всему вольту
4. Чат

> 💡 **Совет:** в настройках плагина **исключи** папки `80-Templates/` (шаблоны с заглушками шумят в поиске).

## Путь B — Локально-приватный (Ollama)

Если регуляторика чувствительная и данные **не должны уходить в облако**.

**Стек:**
- **Ollama** — движок локальных моделей ([ollama.com](https://ollama.com))
- Эмбеддинги: `nomic-embed-text` (768 dim, быстрый) — хорош для русского/мультиязычного
- Генерация: `qwen2.5` (хорош для русского) или `llama3`

**Шаги:**
1. Установить Ollama
2. `ollama pull nomic-embed-text` (эмбеддинги)
3. `ollama pull qwen2.5:14b` (генерация — подбери под железо)
4. В Smart Connections / Copilot выбрать провайдер **Ollama**, адрес `localhost:11434`
5. Чат — данные не покидают машину

## Что выбрать

| Хочешь | Бери |
|--------|------|
| Просто связанные заметки от текущей | Smart Connections |
| Полноценный ассистент-чат по вольту | Copilot for Obsidian |
| Полную приватность | Ollama + любой из плагинов |
| Встроить в продукт Subsoil | ❌ плагины не подойдут → [[90.13-Production-RAG-Pipeline]] |

## ⚠️ Ограничение пути A/B

Плагины работают **только внутри Obsidian**. Для AI-консультанта **внутри продукта Subsoil** (FastAPI + React) нужен программный pipeline → [[90.13-Production-RAG-Pipeline]].

## Перед запуском — настрой системный промпт

Скопируй промпт из [[90.01-System-Prompt]] в настройки плагина (Copilot позволяет задать custom system prompt). Это заставит бота цитировать статьи и указывать фазы.
