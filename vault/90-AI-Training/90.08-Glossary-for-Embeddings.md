# 📖 Глоссарий для embedding-моделей

> Расширенный глоссарий с синонимами для улучшения retrieval.

## Документы

- **Базовый проектный документ** = base project document = главный проект этапа = зелёный документ
- **Технический проектный документ** = tech project = строительный проект
- **Геологический отчёт** = geo report = подсчёт = отчёт о запасах
- **ОВВ** = ОВВС = отчёт о возможных воздействиях = environmental impact report
- **РООС** = раздел охраны окружающей среды = ESIA section
- **Авторнадзор** = АН = author supervision = supervisor's report

## Этапы

- **Разведка** = exploration = поиск = stage 1
- **Оценка** = evaluation = appraisal = stage 2
- **Государственный Баланс** = state balance = state reserves registry = stage 3
- **Подготовительный период** = preparatory period = stage 4
- **Полномасштабная разработка** = full development = production stage = stage 5
- **Ликвидация** = liquidation = abandonment = decommissioning = stage 6
- **Сдача территории** = territory return = surrender = stage 7

## Госорганы

- **МЭиПР** = МЭ = Минэнерго = Ministry of Energy
- **ГКЗ** = state reserves commission
- **ЦКРР** = central commission for exploration and development
- **МД** = МД «Запказнедра» / МД «Южказнедра» = регдеп = regional department
- **НГС** = АО НГС = национальная геологическая служба = national geo service

## Запасы

- **C₂** = категория C2 = предварительно оценённые
- **C₁** = категория C1 = разведанные
- **B** = категория B = доразведанные
- **A** = категория A = детально разбуренные
- **δ запасов** = delta reserves = изменение запасов = reserve change

## Параметры

- **ВНК** = водо-нефтяной контакт = water-oil contact = OWC
- **ГНК** = газо-нефтяной контакт = gas-oil contact = GOC
- **Pнас** = давление насыщения = saturation pressure
- **Pнач.конд** = давление начала конденсации = dew point pressure
- **Pзаб** = забойное давление = bottom hole pressure = BHP
- **Pпласт** = пластовое давление = reservoir pressure
- **ГИС** = геофизические исследования скважин = wireline logging
- **ГДИС** = гидродинамические исследования скважин = well testing
- **КЗН** = коэффициент нефтегазоносности

## Скважины

- **Поисковая** = exploration well = pioneer
- **Оценочная** = appraisal well
- **Опережающе-добывающая** = early production well
- **Добывающая** = producing well = producer
- **Нагнетательная** = injection well = injector
- **Контрольная** = observation well

## Регуляторика

- **КОНН** = Кодекс «О Недрах и Недропользовании» = Subsoil Code
- **ЭК** = Экологический Кодекс = Environmental Code
- **ЕПРКИН** = Единые правила по рациональному и комплексному использованию недр

## Процессы

- **Уведомительный порядок** = notification = простая подача
- **Государственная экспертиза** = state expertise = full state review
- **Авторский надзор** = author supervision
- **Платёжная веха** = payment milestone
