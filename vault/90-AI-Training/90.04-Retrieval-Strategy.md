# 🔍 Стратегия retrieval для RAG

## Структура knowledge base

```
Subsoil-Vault/
├── 00-MOC/        ← entry points (приоритет 1)
├── 10-Foundations/← базовые концепты (приоритет 2)
├── 20-Stages/     ← главный контент (приоритет 1)
├── 30-Documents/  ← карточки документов (приоритет 2)
├── 40-Regulations/← атомы законов (приоритет 2)
├── 50-Authorities/← карточки органов (приоритет 3)
├── 60-Roles/      ← карточки ролей (приоритет 3)
├── 70-Workflows/  ← процессы (приоритет 2)
├── 95-FAQ/        ← готовые сценарии (приоритет 1)
└── 99-Source-Stand/← verbatim (для цитат)
```

## Алгоритм поиска

```python
def retrieve(user_query):
    # 1. Детекция интента
    intent = classify_intent(user_query)

    # 2. Сначала FAQ — топ-сценарии
    faq_hits = search(user_query, folder="95-FAQ", top_k=3)

    # 3. Затем по этапу (если упомянут)
    stage = extract_stage(user_query)
    if stage:
        stage_hits = search(user_query, folder=f"20-Stages/20.{stage:02}-*", top_k=5)
    else:
        stage_hits = []

    # 4. Регуляторика (если упомянута статья)
    article = extract_article(user_query)
    if article:
        reg_hits = search(user_query, folder="40-Regulations", filter=article, top_k=2)
    else:
        reg_hits = search(user_query, folder="40-Regulations", top_k=3)

    # 5. Документы и процессы
    doc_hits = search(user_query, folder="30-Documents", top_k=3)
    wf_hits = search(user_query, folder="70-Workflows", top_k=2)

    # 6. Verbatim (если нужна точная цитата)
    if needs_verbatim(intent):
        verbatim = search(user_query, folder="99-Source-Stand", top_k=2)
    else:
        verbatim = []

    return merge_and_rank(faq_hits, stage_hits, reg_hits, doc_hits, wf_hits, verbatim)
```

## Embedding-стратегия

- **Модель:** multilingual (русский + английский), например `text-embedding-3-large`
- **Chunk size:** ~512 токенов
- **Overlap:** 50 токенов
- **Метаданные** для фильтрации:
  - `stage` (01..07)
  - `tags` (из frontmatter)
  - `type` (regulation / document / authority / role / workflow / faq)

## Citations

После генерации ответа модель должна:
- Цитировать конкретную заметку
- Указывать статью и дату последней редакции
- Не выдумывать, если в извлечённых документах нет ответа
