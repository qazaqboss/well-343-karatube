# 📊 Fine-Tuning Dataset (JSONL)

> Готовый формат для fine-tuning через OpenAI / Anthropic API.

## Формат

```json
{"messages": [
  {"role": "system", "content": "<system prompt из 90.01>"},
  {"role": "user", "content": "<запрос пользователя>"},
  {"role": "assistant", "content": "<идеальный ответ>"}
]}
```

## Примеры (готовы для JSONL экспорта)

### Sample 1
```json
{
  "messages": [
    {"role": "system", "content": "Ты — AI-помощник Subsoil..."},
    {"role": "user", "content": "Когда нужно составить проект разведочных работ?"},
    {"role": "assistant", "content": "Проект разведочных работ должен быть составлен в течение 1 года со дня регистрации контракта на разведку и добычу. Это требование ст. 134 КОНН РК №125-VI от 27.12.2017 (с изм. от 10.06.2025). Срок жёсткий — пропуск создаёт юридическую проблему."}
  ]
}
```

### Sample 2
```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "Что делать, если запасы выросли на 25%?"},
    {"role": "assistant", "content": "δ = 25% > 20% — это триггер обязательного пересчёта запасов (этап 5). Действия: 1) STOP утверждения новых проектов на этих залежах. 2) Подготовить «Пересчёт запасов» по Приказу МИИР №419 (формы отчётов). 3) Особый порядок фаз: сначала сдача в фонды (МД + НГС), потом защита в ГКЗ. 4) Получить протокол ГКЗ. 5) Передача оператору. Только после защиты в ГКЗ можно возобновить утверждения."}
  ]
}
```

## Где брать данные

Q&A файлы из каждой стадии:
- `20-Stages/20.01-Exploration/20.01.10-AI-Training.md`
- `20-Stages/20.02-Evaluation/20.02.10-AI-Training.md`
- ... до 20.07

И FAQ-сценарии из `95-FAQ/`.

## Скрипт сборки (Python)

```python
import json
from pathlib import Path

dataset = []
SYSTEM = open("90-AI-Training/90.01-System-Prompt.md").read()

for ai_training_file in Path(".").rglob("20.*.10-AI-Training.md"):
    content = ai_training_file.read_text()
    # Парсим Q1, Q2, ... и Answer'ы
    qa_pairs = parse_qa(content)
    for q, a in qa_pairs:
        dataset.append({
            "messages": [
                {"role": "system", "content": SYSTEM},
                {"role": "user", "content": q},
                {"role": "assistant", "content": a}
            ]
        })

with open("subsoil_finetune.jsonl", "w") as f:
    for ex in dataset:
        f.write(json.dumps(ex, ensure_ascii=False) + "\n")
```

## Объём корпуса

- 7 стадий × ~10 Q&A = 70 примеров из стадий
- ~14 FAQ-файлов × 1 = 14 примеров
- = ~84 базовых примера

Для серьёзного fine-tuning рекомендуется **минимум 500 примеров**. Расширяйте перефразированиями и edge-cases.
