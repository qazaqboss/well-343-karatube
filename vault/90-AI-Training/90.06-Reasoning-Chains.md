# 🧠 Цепочки рассуждений для обучения CoT

## Шаблон CoT

```
Шаг 1: [определение этапа]
Шаг 2: [выявление применимой статьи]
Шаг 3: [расчёт сроков/проверка условий]
Шаг 4: [идентификация триггеров]
Шаг 5: [рекомендация]
```

## Пример 1: Триггер пересчёта

**Вопрос:** Запасы выросли с 100 до 130 млн т, что делать?

**CoT:**
```
Шаг 1: Определить этап → этап 5 (Полномасштабная разработка), т.к. речь о пересчёте после разбуривания
Шаг 2: Вычислить δ → δ = |130-100|/100 = 30%
Шаг 3: Проверить порог → 30% > 20% → срабатывает триггер пересчёта
Шаг 4: Применимая регуляторика → Приказ МИИР №71 (классификация), Приказ МИИР №419 (формы отчётов)
Шаг 5: Действия → подготовить отчёт «Пересчёт запасов», особый порядок фаз (сначала фонды, потом ГКЗ)
Шаг 6: Блокировка → утверждение новых проектов на залежах заблокировано до защиты в ГКЗ
```

**Ответ:** см. [[FAQ-Reserve-Delta-20]].

## Пример 2: Обнаружение залежи

**Вопрос:** Поисковая скважина дала приток, что готовить?

**CoT:**
```
Шаг 1: Определить этап → переход с этапа 1 на этап 2
Шаг 2: Документы этапа 2 → 4 возможных: оценочный проект, ликвидация разведки, опер. подсчёт, проект ПЭ
Шаг 3: Что нужно сейчас → оценочный проект (если будут оценочные скважины) + проект ПЭ (если будет добыча)
Шаг 4: Сроки → проект ПЭ за 3 месяца со дня решения о ПЭ (ст. 136 КОНН)
Шаг 5: Признаки сложности → проверить (глубина, давление, H₂S, морская локация)
Шаг 6: Рекомендация → стартовать оценочный проект; параллельно — решение о ПЭ
```

**Ответ:** см. [[FAQ-Discovered-Reservoir]].

## Пример 3: Окончание периода добычи

**Вопрос:** До конца периода добычи 2 года, что делать?

**CoT:**
```
Шаг 1: Определить этап → конец этапа 5 (Полномасштабная)
Шаг 2: Опции → продление до 25 лет ИЛИ переход к этапу 6 (ликвидация)
Шаг 3: Условия продления → положительное заключение гос.экспертизы недр на отчёт по подсчёту запасов
Шаг 4: Если продление возможно → запросить экспертизу за 1-1.5 года до конца
Шаг 5: Если ликвидация → начать готовить проект ликвидации (ст. 138 КОНН) сейчас
Шаг 6: Параллельно → готовить обеспечение по ликвидации (Приказ №27-н/к)
```

**Ответ:** зависит от выбора оператора.

## Pattern: Идентификация триггера

| Триггер | Действие |
|---------|----------|
| Признаки сложности | STOP → обновить контракт |
| δ запасов > 20% | Пересчёт + блок утверждений |
| Запасы > 100 млн т / 50 млрд м³ | Обязательство по п.7 ст. 119 |
| Просрочка авторнадзора | Срочная подача |
| Возврат участка | Проект ликвидации + финальный отчёт |
| Подрядчик не сдал данные | Блок платежа подрядчику |
