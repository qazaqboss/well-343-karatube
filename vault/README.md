# 📦 Subsoil Reports Kit — комплект отчётов, паспортов и управленческого учёта

> Дополнение к основному `Subsoil-Vault`. Добавляет **то, чего не было**: на каждом этапе помощник
> **проактивно предлагает сгенерировать отчёт или паспорт**, готовые **PDF-шаблоны под брендом
> «Ваша компания»** и слой **управленческого учёта**. Всё в стиле атомарных заметок Карпати.

## Что внутри

| Папка | Содержание |
|-------|-----------|
| `00-MOC/` | Навигатор «Отчёты и паспорта по этапам» |
| `35-Reports-Templates/` | Каталог + 7 заметок «какой отчёт/паспорт на каждом этапе» |
| `85-Management-Accounting/` | Управленческий учёт: бюджет, вехи, сроки, KPI |
| `90-AI-Training/` | Поведение AI: проактивное предложение отчёта/паспорта |
| `95-FAQ/` | «Какой отчёт когда делать» |
| `PDF/` | 3 готовых шаблона (паспорт, отчёт об испытании, отчёт по этапу) |

## PDF-шаблоны (бренд «Ваша компания»)

- `Shablon-Pasport-Skvazhiny.pdf` — паспорт скважины
- `Shablon-Otchet-Ispytanie.pdf` — отчёт об испытании (5 объектов, снизу вверх)
- `Shablon-Otchet-po-Etapu.pdf` — универсальный отчёт по этапу + управленческий учёт

> Все поля — заполняемые (`____`), вместо «Ваша компания» подставьте свой логотип и реквизиты.

## Как мёржится с основным вольтом

Папки `00-MOC/`, `90-AI-Training/`, `95-FAQ/` совпадают с `Subsoil-Vault` — файлы просто добавятся
(номера новые, ничего не заменяется). Новые папки `35-*` и `85-*` встанут рядом с `30-Documents/`.

## Главная идея

> На **каждом** этапе у недропользователя есть документ, который можно «выпустить». Помощник
> должен **сам предлагать** его сгенерировать — это и есть «продумай везде сделать отчёт».

См. [[00-MOC/08-Reports-By-Stage-MOC]] и [[90.14-Proactive-Report-Offering]].
