# 📜 Приказ МЭ №356 - Промбезопасность на море

## Что регулирует

«Правила обеспечения промбезопасности для опасных производственных объектов проведения нефтяных операций на море». Принят **30.12.2014**, изменения **04.08.2023**. Применяется для морских проектов.
