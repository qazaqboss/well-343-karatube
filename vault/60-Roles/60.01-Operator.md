# 👷 Недропользователь / Оператор

## Кто это

> **Лицо** (юр. или физ.) с правом недропользования на основании лицензии или контракта. **Несёт юридическую ответственность** перед государством за всё, что происходит на участке.

## Что делает на каждом этапе

| Этап | Главные действия |
|------|------------------|
| 1.Разв | Составляет проект разведочных работ (поисковый) |
| 2.Оценка | 4 документа: оценочный проект, ликвидация, опер. подсчёт, ПЭ |
| 3.Баланс | Подсчёт запасов для гос.баланса, анализ разработки |
| 4.Подг. | Проект разработки + техпроект скважин |
| 5.Полн. | Полномасштабная добыча, мониторинг δ запасов |
| 6.Ликв. | Проект ликвидации |
| 7.Сдача | Окончательный отчёт + приёмка комиссией |

## Юридический статус

- Несёт **ответственность** перед государством
- Заключает **договоры** с подрядчиками
- **Получает** или **возвращает** право недропользования

## Финансовая ответственность

- Подписной бонус (на старте)
- Налоги
- **Обеспечение по ликвидации** ([[40-Order-27-NK]]) — закладывается на этапе 1
- Штрафы за нарушения
