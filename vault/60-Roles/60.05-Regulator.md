# 🏛️ Регулятор — общая роль

## Кто это

Любой госорган, участвующий в согласовании или контроле. См. [[03-Authorities-MOC]] для полного списка.

## Уровни

- **Республиканский:** [[50-MEMINPR]], [[50-GKZ]], [[50-TCKRR]], [[50-NGS]], [[50-MCHS]], [[50-MZ]]
- **Региональный:** [[50-MD-Zapkaznedra]], [[50-MD-Yuzhkaznedra]], [[50-Department-Eco-Region]], [[50-Department-Land]]
- **Специальные:** [[50-Forestry-Inspection]], [[50-ZhaiykKaspii]] (морские)

## Общие принципы взаимодействия

- Документы подаются **через МЭиПР** (центральная точка)
- **Уведомительный** порядок для большинства документов
- **Госэкспертиза** — исключение (морские, увеличение участка)
- **Защита в комиссиях** — для базовых проектов (ЦКРР) и подсчётов (ГКЗ)
